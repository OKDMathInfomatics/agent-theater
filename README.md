# agent-theater（エージェント劇場）

Claudeが作業している様子を、ロボットのキャラクターの動きで見せるパネルです。セッションが始まるとチャットの横にパネルが開き、Claudeが使うツールに合わせてキャラクターが移動します。Web検索では地球儀へ、ファイルの読み込みでは資料の山へ、コマンドや編集では机のモニターへ向かい、サブエージェントを呼ぶと分身が奥の作業場を回ります。質問では「？」の札を掲げ、回答が終わると箱を閉じて紙吹雪で喜び、しばらくすると眠って次の依頼を待ちます。

パネルを閉じたときは `/agent-theater` で開き直せます。ターミナルでは絵の代わりに今の状態を文字で表示します。

## インストール

デスクトップアプリでは、プロンプト欄の横の「＋」→「プラグイン」→「マーケットプレイスを追加」で `<GitHubユーザー名>/agent-theater` を追加し、「プラグインを追加」から agent-theater を選びます。

ターミナルの Claude Code では次の1行です。

```
/plugin install agent-theater --marketplace <GitHubユーザー名>/agent-theater
```
